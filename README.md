# 日米業種リードラグ予測ソフト

中川 慧・竹本 悠城・久保 健治・加藤 真大「部分空間正則化付き主成分分析を用いた日米業種リードラグ投資戦略」(人工知能学会 金融情報学研究会 SIG-FIN-036-13) の実装です。

**NY 市場の当日終値から、翌営業日の東京市場（寄付き→大引け）を予測します。**

出力は 2 つ:

1. **業種ランキング** — TOPIX-17 業種 ETF の相対的な強弱（論文の手法そのもの）
2. **市場全体の方向** — 翌日の東京市場が上がるか下がるか（別モデル。理由は後述）

## 実装の中身

### 時間軸

| | |
|---|---|
| 情報 | 米国業種 ETF の当日 close-to-close リターン（21:00 UTC 確定） |
| 執行 | 日本業種 ETF の翌営業日 open-to-close リターン（翌 00:00 UTC 寄付き） |

東京 t の引け（06:00 UTC）は米国 t の引け（21:00 UTC）より前なので、米国 t の情報は東京 t+1 で初めて価格に入り得ます。ここがこの戦略の全てです。

### シグナル（論文 3 章）

```
窓 W_t = {t-L, ..., t-1} で標準化 →  相関行列 C_t
C_t^reg = (1-λ) C_t + λ C_0                      … 部分空間正則化 (式13)
C_t^reg = V Λ V'  →  上位 K 本を V_U (米), V_J (日) に分割
f_t = V_U' z_U,t                                  … 米国ショックの射影 (式18)
ẑ_J,t+1 = V_J f_t = B_t z_U,t,   B_t = V_J V_U'   … 日本側へ復元 (式19-21)
```

`C_0` は事前部分空間 `V_0 = [v1, v2, v3]`（グローバル / 国スプレッド / シクリカル・ディフェンシブ）から作ります。

主要パラメータ（すべて CLI で変更可能）: `L=60`, `K=3`, `λ=0.9`, `q=0.3`

### 先読み（look-ahead）の排除

- 平均・標準偏差・相関はすべて `{t-L, ..., t-1}` から計算し、時点 t のデータを含めない
- シグナルに使う t のデータは**米国のリターンのみ**
- 執行は必ず t+1
- `--prior-mode expanding` を使うと `C_full` も t 以前のデータのみで再推定する（完全に因果的）

`tests/test_model.py::test_no_lookahead` が、将来のデータを乱数で差し替えても過去のシグナルが 1 ビットも変わらないことを検証しています。

## 実装して分かった重要なこと（必ず読んでください）

### 1. このシグナルは「市場全体の方向」を予測しません

これは実装のバグではなく、手法の構造的な性質です。

事前ベクトル `v1`（全銘柄一様）と `v2`（米国 +/日本 −）が張る空間は

```
span{v1, v2} = span{(1_米, 0), (0, 1_日)}
```

と一致します。この 2 次元部分空間への射影行列は**日米ブロック対角**なので、伝播行列 `B = V_J V_U'` に対する `v1` と `v2` の寄与はちょうど打ち消し合います。結果として `B` に残る日米クロス成分は実質的に `v3`（シクリカル/ディフェンシブ）だけになり、

```
mean_j(ẑ_J,t+1) ≈ 0
```

となります。合成データでも実データでも、シグナルの断面平均の標準偏差は個別シグナルの 1/100 程度です。つまり**設計上、完全な市場中立の相対シグナル**です（`tests/test_model.py::test_global_and_country_modes_cancel_across_markets` で検証）。

そこで市場全体の方向は `leadlag/direction.py` の別モデル（ローリング OLS: 当日の米国 EW リターン → 翌日の東京 EW 日中リターン）で推定しています。素朴ですが、これがリードラグ仮説の市場レベルでの素直な形です。合成データでの的中率は 57% 前後。**実データでの現実的な期待値は 53〜56% 程度**で、それ以上を期待しないでください。

### 2. λ=0.9 はかなり強い正則化です

λ=0.9 では `V^(K)` がほぼ事前部分空間そのものになり、シグナルは実質的に

> 「米国のシクリカル業種がディフェンシブ業種を上回った日は、翌日の日本もシクリカルを買う」

という 1 本のルールに縮退します。実際に `predict` の出力を見ると、ラベル付けされた 8 業種（シクリカル: 1618/1625/1629/1631、ディフェンシブ: 1617/1621/1627/1630）だけがはっきり ±0.14 に張り付き、残りの 9 業種はほぼ 0 になります。

つまり**論文の高い成績は、部分空間正則化という手法そのものよりも、シクリカル/ディフェンシブのラベル付けが正しいかどうかにほぼ全面的に依存しています**。しかもそのラベルは論文で全期間について事後的に固定されています。

必ず `python -m leadlag.cli sweep` で λ を振って、性能が λ に対してどう動くかを確認してください。λ=0.9 だけが突出して良い場合、それは手法の頑健性というよりラベルの当たりを見ている可能性があります。

### 3. 論文の再現で注意すべき点

| 項目 | 状況 |
|---|---|
| 年率換算係数 | 論文の式(27)(28) は 12 だが、日次リターンで表2の水準（AR 23.79%）と整合するのは 252。本実装は 252 が既定（`--ann-factor` で変更可） |
| 取引コスト | 論文は考慮していない。毎日 17 銘柄をリバランスするので実際には効く。`--cost-bps 5` などで必ず確認すること |
| XLC / XLRE | 上場が 2018年 / 2015年 で学習期間にデータが無い。ペアワイズ相関＋ブロック平均補完で処理（`estimate_c_full`） |
| `C_full` の期間 | 論文は 2010-2014 で固定。バックテスト開始は既定で 2015-01-01 以降にしてある |
| データ品質 | yfinance の日本 ETF の**始値**は欠損・異常値が出ることがある。open-to-close リターンを直接使うので、ここの品質が結果に直結する。`python -m leadlag.cli data` で N と統計量を必ず確認すること |
| 流動性 | TOPIX-17 ETF は銘柄によって出来高が細い。バックテスト上のリターンと実際の約定は乖離し得る |

## 検証状況

合成データによる 30 件のテストが通っています。

- 事前基底の直交性、`C0` が相関行列であること、`rank(B) ≤ K`（命題1）、`ẑ = B z`（式20）
- 理想モデル下で推定した `B` が真の `V_J V_U'` と相関 0.8 超（命題2）
- IC の t 値 > 4（理想モデル下）
- 将来データを差し替えても過去のシグナルが不変（先読みなし）
- ノイズのみのデータでは R/R がほぼ 0（見せかけの収益が出ない）
- 推定誤差が大きい設定では正則化ありが正則化なしを上回る（論文 4.4 節の主張）
- 方向モデルにも先読みが無いこと
- 毎朝のページが外部 CDN に依存しないこと、履歴の採点が実現リターンと一致すること

**実データでのバックテストはまだ実行していません。** この開発環境から Yahoo Finance に接続できなかったためです。お手元で `python -m leadlag.cli backtest` を実行して、論文の表2（PCA_SUB: AR 23.79%, RISK 10.70%, R/R 2.22, MDD 9.58）とどれだけ一致するかを確認してください。
