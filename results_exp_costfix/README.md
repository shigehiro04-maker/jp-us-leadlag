# 回転率の修正後の再計算（2026-10-09）

`results_exp/REPORT_EXPERIMENTS.md`（2026-09 作成）は、寄付き→大引けのリターンに、
ポジションを持ち越す場合の回転率（前日とのウェイト差）を組み合わせていた。
寄付きで建てて大引けで手仕舞う運用では、ウェイトが前日と同じでも毎日往復するため、
回転率は常に 2Σ|w| = 4 になる。そのため損益分岐コストを約 2 倍に見積もっていた。

`leadlag/backtest.py` に `Params.holding` を追加し、2 つの持ち方を分けて再計算した
（λ=0.9, K=3, L=60, q=0.3, 事前行列固定、データ 2010-01-04〜2026-10-08、キャッシュ使用）。

- `intraday/`  … 寄付き→大引けで毎日往復（論文・日次ページと同じ）。回転率 4/日で一定
- `overnight/` … 次の執行日の寄付きまで持ち越し、差分だけ売買。リターンは寄付き→寄付き

## 損益分岐コスト（片道 bp、全期間、平滑化は素の EWMA）

| 半減期 | 旧レポート | 修正後 intraday | 修正後 overnight | AR（intraday / overnight） |
|---|---:|---:|---:|---:|
| なし | 3.67 | 2.02 | 4.46 | 20.4% / 24.4% |
| 3 | 5.86 | 1.41 | 5.70 | 14.2% / 14.0% |
| 5 | 7.02 | 1.38 | 5.13 | 13.9% / 10.3% |
| 10 | 8.24 | 1.15 | 5.00 | 11.6% / 7.3% |

## 結論

1. 日中だけで往復する限り、平滑化は回転率を下げない。シグナルが弱まるぶん損益分岐はむしろ下がる（2.0→1.2bp）。
2. 持ち越せば回転率は 2.2→0.6 まで下がるが、平滑化でリターンも落ちるため、損益分岐は 4.5〜5.7bp にとどまる。
   持ち越しは最大 DD も大きい（55%）。
3. 片道 10bp では、どの組み合わせでも全期間・2024 年以降ともに R/R はマイナス。
   旧レポートの「平滑化で損益分岐 8bp まで上がる」は成り立たない。
